## Матрица тестового покрытия

Чек-лист:
| Number | Test |
| ------ | ---- |
| 01 | Проверить страницу на верность текста |
| 02 | Проверить кнопку выпадающего меню |
| 03 | Убедиться, что все кнопки с ссылками работают и перенеправляют на верные старницы |
| 04 | Проверить, что страница адаптивна и верно отображается на разных устройствах и в разных форматах |
| 05 | Проверить, что дизайн соответствует корпоративному стилю |
| 06 | Блоки с текстом и иллюстрациями не теряют читаемость при большом масштабировании |
| 07 | Страница корректно работает в разных браузерах и ОС |
| 08 | Проверить, что страница загружается быстро, нет зависаний при прокрутке и при взаимодействии с элементами |
| 09 | Корректное отображение для мобильных устройствах |
| 10 | Внешние ссылки открываются в новом окне |
| 11 | Логотип компании ведет на стартовую страницу |
| 12 | Адрес почты и мессенджеров настроен верно |
| 13 | Включена переадресация на страницу об ошибке 404 |

Матрица: 
1. Критический функционал

| Функционал | Номер тест-кейса | Описание функционала | 
| ---------- | ---------------- | --------------------------- |
| Читаемость текста | 01, 05 | Главная информация передается через текст, он обязан быть верным | 
| Загрузка страницы | 08, 13 | Без верной загрузки страницы сайт не несет в себе ценности | 
| Кнопка "Подробнее о платформе" | 03, 10 | Кнопка ведет на вспомогательную страницу, через которую можно зарегестрироваться на обучение |
| Кроссплатформенность | 04, 07 | Страница должна верно отображаться на всех платформах для удобного взаимодействия с ней | 

2. Важный функционал

| Функционал | Номер тест-кейса | Описание функционала | 
| ---------- | ---------------- | --------------------- |
| UI страницы | 05 | Внешний вид страницы помогает донести информацию, но не критична для работы сайта | 
| Адаптивность верстки | 04, 06, 09 | Красивый внешний вид в любом формате страницы не критичен для работы, но приятен для восприятия | 
| Кнопка меню | 02, 03 | Не важна для главной цели страницы, но поможет найти дополнительную информацию |  
| Кнопки почты и мессенджеров | 12 | Помогает связаться при необходимости |

3. Вспомогательный функционал

| Функционал | Номер тест-кейса | Описание функционала | 
| ---------- | ---------------- | --------------------- |
| Кнопка "Сбер 21" | 03, 10, 11 | Ведет на главную страницу, на которую можно перейти через меню |
| Кнопки кампусов других городов | 03, 10 | Не относится к сути страницы, просто помощь в навигации при необходимости | 
| Анимация при наведении на кнопку | 03 | Дает красивый визуальный эффект, но можно обойтись и без этого |
