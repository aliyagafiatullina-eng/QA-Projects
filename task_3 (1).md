## Тест-план

#### 1. Вступление

Настоящий документ является тест-планом страницы "Корпоративное обучение" сайта "Школа 21". В нем определены цели и объем тестирования(что входит и что исключено), критерии приемки, применяемые подходы и техники, необходимые ресурсы и окружение, график работ, роли/ответственности и риски. Документ служит основой для согласования ожиданий между заказчиком, разработкой, QA и исользуется для планирования, контроля и отчетности по тестированию.

#### 2. Функциональности, которые будут протестированы

>Форма заявки
1. Обязательные поля
2. Валидность данных
3. Отправка

>Интерфейс
1. Внешний вид страницы на разных устройствах
2. Верность текста
3. Кроссплатформенность

>Навигация
1. Переход по ссылкам на странице
2. Работоспособность кнопок

> Медиа
1. Фото
2. Видео 



#### 3. Функциональности, которые НЕ будут протестированы

1. Авторизация - не относится к рассматриваемой странице.
2. Ссылки на внешние сайты - вне нашей зоны ответственности.
3. Скорость загрузки сайта 
4. Безопасность сервера, резервное копирование - ответственность DevOps.

#### 4. Тестовые единицы

> Форма заявки
1. Обязательные поля для заполнения в формах 
2. Валидация полей: пустые значения, неверные данные
3. Отправка данных, сообщения об ошибках

> Интерфейс
1. Внешний вид страницы на разных устройствах(соответствие расположения, цвета, читаемость)
2. Отсутствие ошибок в тексте(заголовок, текстовые блоки)
3. Работоспособность сайта на разных браузерах(Windows, macOS, iOS, Android)

> Навигация
1. Кликабельность кнопок(переход по ссылкам, открытие скрытой информации)
2. Верность перехода по ссылкам 

> Медиа
1. Воспроизведение видеоряда(картинка, звук, кнопки управления)
2. Отображение фотографий(размер, разрешение)

#### 5. Задачи тестировщиков

1. Подготовка тест-кейсов/данных, актуализация по изменениям требований.
2. Фиксация артефактов.
3. Заведение дефектов(создание баг-репорта).
4. Еженедельный Test Report.
5. Регрессия и mini-smoke на каждый билд.

#### 6. Потребности в окружении

1. OS/Browser: Win 10/11 + Chrome/Edge, Firefox >= 128; macOS 14 + Safari >= 17.
2. Сеть: стабильная; без VPN
3. Браузерные расширения: отключены.
4. Инструменты: средство скриншотов, таблица кейсов, трекер дефектов.
5. Аккаунты: не требуются (публичный поиск).

#### 7. Персонал и обучение

1. Состав: 1 Test Lead, 1-2 Manual QA
2. Ответственности: Test Lead - план/матрица окружений, приемка кейсов, отчеты, коммуникации; Manual QA - дизайн/прогоны кейсов, артефакты, дефекты/ретесты.

#### 8. Артефакты тестирования

1. Тест-план с журналом изменений.
2. Реестр тест-кейсов/чек-лист регрессии.
3. Отчеты о прогонах, еженедельные Test Report.
4. Баг-репорты со скриншотами.
5. Финальный Test Summary Report(метрики, риски, рекомендации).
